Who lives Outside Melbourne's 15-Minute Library Zone?

This project explores pubilic library accessibility across Greater Melbourne. The first visualisation adapts the official Vega-Lite choropleth map example: instead of Us country unemployment, it maps libraries per 10,000 residents accross SA2 areas.

Most outer SA2 areas apprea in the lowest access range, while higher libraty access is concentrated in selected inner and established suburban areas. This map provides the baseline for the later cutural desert analysis, where library access will be compared with socioeconomic disadvantage.

This symbol map shows where library service nodes are located across Greater Melbourne. Larger circles indicate SA2 areas with multiple libraries, helping reveal whether cultural infrastructure is concentrated in only a small number of local centres.

Data sources: ABS SA2 boundaries 2021, ABS SEIFA 2021, Victoria public library locations dataset. Author: Ran Xiao. Created for FIT2179 Data Visualisation 2.
