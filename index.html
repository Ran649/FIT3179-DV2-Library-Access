Who Lives Outside Melbourne's 15-Minute Library Zone?

This project explores public library accessibility across Greater Melbourne. Public libraries are important cultural and learning spaces, but access to them is not evenly distributed. This visualisation investigates which Greater Melbourne communities have nearby library services, which areas rely more heavily on transport, and where low access overlaps with socioeconomic disadvantage.

This symbol map shows where library service nodes are located across Greater Melbourne. Larger circles indicate SA2 areas with multiple libraries, helping reveal whether cultural infrastructure is concentrated in only a small number of local centres.

Most outer SA2 areas appear in the lowest access range, while higher library access is concentrated in selected inner and established suburban areas. This map provides the baseline for the later cultural desert analysis, where library access will be compared with socioeconomic disadvantage.

This scatterplot compares socioeconomic disadvantage with library access. SA2 areas in the lower-left pattern combine lower IRSD scores with limited or no local library access, making them important candidates for later cultural desert analysis.

Data sources: ABS SA2 boundaries 2021, ABS SEIFA 2021, Victoria public library locations dataset. Author: Ran Xiao. Created for FIT2179 Data Visualisation 2.
